# OpenFlow Finance Protocol

OpenFlow Finance Protocol is a lightweight DeFi and open finance project built on OPN Testnet.

## Overview

The project demonstrates how decentralized financial interaction can be implemented through simple and transparent smart contracts.

## Features

- Permissionless interaction
- Smart contract deployment
- Open finance experimentation
- EVM compatibility

## Stack

- Solidity
- Remix IDE
- MetaMask
- OPN Testnet

## Deployment

Compiled and deployed on OPN Testnet.

## Vision

Create transparent and accessible financial infrastructure.
